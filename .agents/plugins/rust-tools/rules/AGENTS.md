# Алгоритм работы с Rust-кодом

1. После любого изменения `.rs` файлов вызывай `lsp_diagnostics` (и при необходимости `lsp_code_actions`) через плагин `rust-tools_rust-lsp`, пока список ошибок и предупреждений не станет пустым.
2. Не запускай `cargo check` в терминале для промежуточных проверок — используй для этого LSP (`lsp_diagnostics`).
3. Перед тем как сдать задачу, обязательно запусти `cargo test` в терминале и убедись, что все тесты проходят.
