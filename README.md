# Windows-Native Screen Translator (Rust)

Высокопроизводительный экранный переводчик для **Windows 10/11**, спроектированный специально для:
1. **Компьютерных игр** (визуальные новеллы, RPG, экшены в Borderless / Fullscreen).
2. **Манги и комиксов** (детекция текстовых бабблов, наложение перевода точно поверх оригинала).
3. **Ранобэ и текстовых новелл** (сохранение контекста, поддержка глоссария имен и терминов).

Размер исполняемого файла — всего **~5.7 МБ** (без тяжелых зависимостей Python, PyTorch или CUDA).

---

## Архитектурные особенности

- **Захват экрана без лагов:**
  Используется современный `Windows.Graphics.Capture API` (WinRT) с аппаратно ускоренными текстурами Direct3D 11 (`DXGI_FORMAT_B8G8R8A8_UNORM`).
  - При выделении зоны (ROI) обрезка выполняется **напрямую на GPU** (`CopySubresourceRegion`), минуя PCIe шину.
  - Флаг `DrawBorderSettings::WithoutBorder` убирает системную желтую рамку Windows 10/11.
  
- **Оверлей с защитой от захвата кадра:**
  - Окно создано через Win32 API со стилями:
    `WS_POPUP | WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_TOPMOST | WS_EX_NOACTIVATE`.
  - Применен флаг композитора DWM:
    ```rust
    SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE); // 0x00000011
    ```
    Это гарантирует, что оверлей **физически невидим для захвата экрана**, предотвращая зацикливание и повторное распознавание собственного перевода.
  - Окно не перехватывает клики мыши (`WS_EX_TRANSPARENT`), позволяя беспрепятственно управлять игрой.

- **Аппаратный рендеринг Direct2D / DirectWrite:**
  - Отрисовка карточек перевода и HUD-интерфейса выполнена через `ID2D1DCRenderTarget` с субпиксельным сглаживанием текста и `D2D1_ALPHA_MODE_PREMULTIPLIED`.
  - Плашки перевода отображаются в виде скругленных полупрозрачных панелей с неоновой окантовкой.

- **Сверхбыстрый нативный OCR:**
  - Интеграция с системным `Windows.Media.Ocr.OcrEngine` (WinRT). Задержка распознавания: **~40–120 мс** на 1080p/4K кадр при 0% нагрузки на CPU.
  - Встроенный алгоритм кластеризации строк в смысловые блоки и бабблы (объединяет разорванные строки диалога в единые предложения для качественного машинного перевода).

- **Контекстный перевод и лорбук:**
  - Клиент перевода с защитой от сбоев сети.
  - Система глоссария (`ContextManager`), позволяющая жестко фиксировать перевод игровых терминов (HP, MP, EXP, Lv) и имена персонажей.

- **Умный авто-режим (Dialogue Watcher):**
  - При включении авто-режима (`Alt + A`) фоновый воркер анализирует хэш зоны диалога. Если экран статичен (текст не изменился), повторный OCR не вызывается, экономя ресурсы GPU.

## Горячие клавиши (Hotkeys)

| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| **`Alt + T`** | **Перевести** | Захватывает активную зону диалога (или весь экран), распознает и выводит перевод. |
| **`Alt + S`** | **Выбрать зону (ROI)** | Включает интерактивный режим выделения: экран затеняется, курсор превращается в перекрестие. Выделите рамку диалогового окна левой кнопкой мыши. Нажмите `Esc` для отмены. |
| **`Alt + A`** | **Авто-режим [ВКЛ/ВЫКЛ]** | Автоматически отслеживает появление нового текста в выбранной зоне диалога. |
| **`Alt + C`** | **Очистить** | Скрывает текущие карточки перевода с экрана. |
| **`Alt + Q`** | **Выход** | Завершает работу приложения. |

## Структура проекта

```
src/
├── types.rs              # Геометрия (ScreenRect), структуры распознанных слов и карточек перевода
├── capture/
│   └── mod.rs            # Захват кадров через Windows.Graphics.Capture + GPU Crop
├── ocr/
│   └── mod.rs            # WinRT OcrEngine + алгоритм кластеризации строк диалога в бабблы
├── translator/
│   └── mod.rs            # Асинхронный клиент перевода + Лорбук/Глоссарий + История
├── overlay/
│   ├── mod.rs            # Win32 HWND менеджер, перехват хоткеев, обработка мыши
│   └── renderer.rs       # Direct2D + DirectWrite рендерер со скругленными карточками и HUD
├── app.rs                # Центральный координатор событий и фоновый авто-воркер
└── main.rs               # Точка входа, запуск и логирование
```

## Поддержка японского языка (для Manga и JRPG)

Если вам требуется распознавание японского текста (JRPG, визуальные новеллы, манга):
1. Откройте **Параметры Windows** -> **Время и язык** -> **Язык и регион**.
2. Нажмите **Добавить язык** -> выберите **Японский (日本語)**.
3. Убедитесь, что отмечена галочка **«Распознавание текста (OCR)»** и дождитесь загрузки пакета (~15 МБ).
4. После этого встроенный системный `Windows.Media.Ocr` автоматически сможет распознавать как горизонтальный, так и вертикальный японский текст.
