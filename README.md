# Screen Translator

### Проверка качества OCR

Auto сравнивает WinRT и RapidOCR по областям текста и сохраняет строки, найденные
только одним движком. Уверенность RapidOCR используется при выборе перекрывающихся
результатов. WinRT сравнивает обработанный кадр с исходным изображением.

Кадры с длинной стороной больше 2000 пикселей обрабатываются участками до 1200×1200
с перекрытием 160 пикселей. Это сохраняет размер мелких букв, но увеличивает время
обработки больших экранов. Для игр предпочтительно выделить область диалога.
Автоматический режим повторяет захват через 250 мс и ожидает стабильного кадра.
Каждая операция WinRT OCR ограничена двумя секундами; отмена задачи также запрашивает
отмену операции Windows. Ошибка локального OCR допускает Vision только при включённом
`vision_fallback` и настроенном ключе.

При загрузке RapidOCR готовность сообщается после загрузки модели выбранного языка;
на это отведено до 30 секунд. Полноэкранный захват охватывает все мониторы;
для нескольких мониторов используется GDI, а область на основном мониторе сохраняет GPU-захват.

Ошибки перевода показывают причину и число неудачных блоков. Автоматические повторы
при временных сбоях откладываются на 5–60 секунд, при HTTP 429 учитывается `Retry-After`.
Ошибки ключа, модели или запроса приостанавливают автоповторы. `Alt+T` разрешает ручную
повторную попытку; смена движка также снимает паузу. Изменения `config.toml` применяются
после перезапуска приложения.
Повторы Vision ограничиваются отдельно: его ошибка не останавливает локальный OCR
и перевод распознанного текста.

Проверочный набор и команда измерения ошибок символов, пропущенных строк и времени:
[tests/fixtures/ocr](tests/fixtures/ocr/README.md).

Высокопроизводительный оверлей-переводчик экрана для Windows (игры, визуальные новеллы, манга и комиксы).

Программа перехватывает кадры с экрана через аппаратный GPU-захват, распознает текст с помощью локального OCR или нейросетевого помощника, переводит его в реальном времени и отображает стилизованные плашки с переводом прямо поверх игрового окна.

## Возможности

- **Аппаратный захват экрана:** Быстрый захват кадра через Direct3D11 / Desktop Duplication API с автоматическим резервным переключением на GDI BitBlt. Окно оверлея исключено из захвата (`WDA_EXCLUDEFROMCAPTURE`), исключая рекурсивное наложение.
- **Гибкий OCR:**
  - `WinRT` — встроенный системный Windows.Media.Ocr (работает мгновенно из коробки без сторонних зависимостей).
  - `RapidOCR` — локальный Python-помощник на базе ONNX Runtime (высокая точность на сложных фонах и шрифтах).
  - `Авто (Auto)` — многоступенчатый конвейер с автоматической оценкой качества и Vision-fallback.
- **Поддержка множества движков перевода:**
  - **Google Translate** — работает сразу и бесплатно без необходимости API-ключа.
  - **DeepL API** — контекстный перевод высокой точности.
  - **Google Gemini** — перевод с учётом контекста истории диалогов (`gemini-2.5-flash` / `gemini-3.8-flash`).
  - **OpenAI / Groq** — совместимость с OpenAI API и высокоскоростными LLM (Llama, GPT-4o-mini).
- **Direct2D оверлей:** Полноэкранное прозрачное окно с отрисовкой через аппаратный Direct2D/DirectWrite, не прерывающее игровой процесс.
- **Интерактивный HUD и ROI:** Выделение произвольной области экрана мышью с автоматическим возвратом фокуса игре.
- **Словарь под курсором:** Удержание клавиши `Shift` мгновенно распознает и переводит слово или фразу под указателем мыши, отображая словарные значения и примеры.
- **Диалоговый авто-режим:** Фоновый отслеживатель экрана (Dialogue Watcher) определяет смену реплик по хеш-сигнатуре кадра и переводит новые фразы без участия пользователя.

## Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| `Alt + T` | Распознать и перевести текущий экран / выбранную область (ROI) |
| `Alt + S` | Режим выделения области (ROI) мышью (клик без перетаскивания сбрасывает на полный экран) |
| `Alt + A` | Включить / выключить автоматический перевод диалогов (Auto Mode) |
| `Alt + P` | Циклическое переключение движка перевода (`Google` → `DeepL` → `Gemini` → `OpenAI/Groq`) |
| `Alt + O` | Циклическое переключение OCR-режима (`WinRT` → `RapidOCR` → `Авто`) |
| `Alt + C` | Скрыть плашки перевода и сбросить выбранную область ROI |
| `Alt + Q` | Завершить работу приложения |
| `Shift` (удержание) | Мгновенный словарный перевод слова / строки под курсором мыши |
| `Esc` | Отмена режима выделения области |

Чтобы сохранить слово в карточки, наведите курсор на слово и удерживайте `Shift`.
Когда появится перевод с контекстом, нажмите маленькую кнопку `+` справа от окна перевода.
Слово, перевод и контекст добавятся в UTF-8 файл `cards.txt` рядом с исполняемым файлом.
Статус программы покажет результат сохранения; существующие записи сохраняются.

## Требования к системе

- **ОС:** Windows 10 (версия 1803+) или Windows 11 (x86_64).
- **Rust:** Stable Rust toolchain (`msvc`).
- **Python:** Python 3.10–3.13 (опционально, требуется только при использовании движка `RapidOCR`).

## Сборка и запуск

### 1. Сборка приложения на Rust

```powershell
# Клонирование репозитория
git clone https://github.com/your-repo/Screen_translator.git
cd Screen_translator

# Сборка оптимизированного исполняемого файла
cargo build --release

# Запуск приложения
cargo run --release
```

### 2. Настройка OCR-помощника RapidOCR (опционально)

Если вы хотите использовать модели PP-OCR / RapidOCR для распознавания сложного текста на шумном фоне:

```powershell
cd ocr_helper
# Создание виртуального окружения и установка зависимостей:
.\setup.ps1

# Загрузка предобученных моделей распознавания:
.\.venv\Scripts\python.exe download_models.py
cd ..
```

## Конфигурация (`config.toml`)

Файл конфигурации `config.toml` создаётся автоматически со значениями по умолчанию при первом запуске, либо настраивается вручную:

```toml
# Активный движок перевода ("google", "deepl", "gemini", "openai_compatible")
provider = "google"

# Режим OCR ("winrt", "helper", "auto")
ocr_engine = "winrt"

# Языки перевода
source_lang = "en"
target_lang = "ru"

# Интервал авто-режима (в миллисекундах)
auto_mode_interval_ms = 1200

# Настройки API (при использовании облачных провайдеров)
# deepl_api_key = "your-deepl-key:fx"
# gemini_api_key = "your-gemini-key"
# openai_api_key = "your-openai-or-groq-key"
```

Для Vision через Groq дополнительно задайте `openai_vision_model` — действующий ID
модели с поддержкой изображений. Программа проверяет его наличие в `/models`;
снятые с обслуживания Llama 3.2 Vision Preview не поддерживаются. Текстовая модель
и Vision-модель настраиваются отдельно. `vision_fallback` по умолчанию выключен.

---

При `dump_ocr = true` программа хранит последние 20 запусков диагностики в `debug/ocr/`.
В каждом каталоге находятся исходный снимок `frame.png`, итоговый текст `result.txt`
и ответ RapidOCR в `recognition.json` либо описание режима WinRT в `engine.txt`.
